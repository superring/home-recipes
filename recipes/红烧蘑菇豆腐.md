# 红烧蘑菇豆腐

来源：[下厨房](https://www.xiachufang.com/recipe/104589509/)
标签：素菜、快手
用时：20分钟

## 成品图

![成品图](../images/红烧蘑菇豆腐-成品.jpg)

## 材料

- 豆腐 1块
- 蘑菇 8-10个
- 蒜 2瓣
- 生抽 3勺
- 蚝油 2勺
- 盐 少许

## 做法

1. 蘑菇切片备用
2. 老豆腐切片备用
3. 热油锅，把豆腐煎至两面金黄盛出备用
4. 热油锅，下蒜炒香，下蘑菇翻炒至蘑菇完全变软
5. 加酱油、蚝油和盐调味，加豆腐翻炒，加一点水煮一会儿（大约五分钟），让豆腐入味后即可出锅
6. 盛出
